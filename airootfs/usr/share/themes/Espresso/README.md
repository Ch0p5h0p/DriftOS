# Espresso GTK Theme

A warm, muted dark GTK theme based on the `espresso` palette.

## Install

Copy the `Espresso` directory to either:

- `~/.themes/` for the current user
- `/usr/share/themes/` for all users

For the Arch ISO, the system-wide destination is:

```text
airootfs/usr/share/themes/Espresso/
```

## Enable in XFCE

Open **Settings → Appearance → Style** and select **Espresso**.

The GTK theme does not include XFWM window decorations, icons, cursors, or wallpapers. Those are separate theme components.
