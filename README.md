# DriftOS

My custom arch-based OS

## Included Packages

### Programming
- **C/C++:** `base-devel`, `clang`, `cmake`, `ninja`, `meson`, `pkgconf`
- **Rust:** `rustup`
- **Assembly:** `nasm`
- **Lua:** `lua`, `luajit`, `luarocks`
- **Python:** `python`
- **OCaml:** `ocaml`, `opam`, `dune`

### Development Utilities
`git`, `neovim`, `ripgrep`, `fd`, `fzf`, `jq`, `file`, `tmux`

### Debugging & Reverse Engineering
`rizin`, `rz-ghidra`, `capstone`, `gdb`, `gef`, `strace`, `ltrace`, `valgrind`

### Desktop & Interface
`xfce4`, `fish`, `alacritty`
